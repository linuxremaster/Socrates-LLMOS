# reference/ — Archival Notice

Everything under `reference/` is historical, experimental, or research
material. Nothing here is current authority or a declaration of
current implementation. Current behavior is defined only by `kernel/`,
`llmos_toolkit/`, and the active `docs/` set.

`llmos_architecture_history/` in particular contains documents using
stronger runtime language than the current kernel — "Core Runtime,"
"Mission Runtime," full runtime specifications. Those describe a
superseded or experimental architecture, not the current kernel. See
`docs/LLMOS_SCOPE_AND_BOUNDARIES.md` for the current, authoritative
kernel-vs-toolkit-vs-historical distinction.

`pilot_and_research/` contains unrun harness code and research
conversation exports — read for ideas, don't build on directly without
first re-verifying it against current kernel/toolkit state.

**End Archival Notice**
