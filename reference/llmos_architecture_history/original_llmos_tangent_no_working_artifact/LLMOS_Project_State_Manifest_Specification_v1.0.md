# LLMOS Project State Manifest Specification v1.0

## Purpose

Defines the canonical, evidence-based snapshot of a project's execution
state.

## Principles

-   Evidence before inference.
-   Preserve completed work.
-   Never restart verified components.
-   Record unknowns explicitly.

## Required Sections

1.  Project Identity
2.  Primary Objective
3.  Acceptance Criteria
4.  Latest Stable State
5.  Last Verified Execution Point (LVEP)
6.  Current Architecture
7.  Dependency Graph
8.  Component Status Matrix
9.  Completed Milestones
10. Pending Tasks
11. Blocked Tasks
12. Known Constraints
13. Risks
14. Rollback Point
15. Next Atomic Step
16. Evidence Summary
17. Confidence Assessment

## Maintenance

Regenerate after meaningful verified changes.
