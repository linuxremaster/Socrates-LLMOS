# NOTICE

**Project name:** Socrates LLMOS

This name is the project's own nickname, earned honestly over the course
of its development — not a rebrand of any code. The Python package stays
named `llmos_toolkit` (renaming it breaks `python -m llmos_toolkit` and
every plugin's imports — this was tested and confirmed the hard way
during development). "Socrates LLMOS" is what the humans call the whole
effort; the code doesn't need to know its own nickname.

**Why the name:** the one idea that held up across every layer of this
project — the kernel's evidence tiers, the multi-instance review process,
a philosophy tangent that arrived at the same place independently — was
some version of *"know where you don't know."* That's Socrates' whole
contribution to epistemology, twenty-four centuries early. Seemed fair
to name it after him rather than after the framework that almost
buried it in architecture.
